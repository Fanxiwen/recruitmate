## 一、项目定位

面向公司招聘场景的 AI 驱动招聘平台，覆盖「发布岗位 → 简历投递 → AI 智能匹配 → 两轮面试 → Offer 审批定薪 → 入职」的完整业务闭环，并按 OA 标准实现审批链、状态机约束与全链路留痕。

## 三、核心功能

**1. 招聘业务闭环**
- 岗位发布审批（四眼原则：提交人不能自批）；入职满编岗位自动关闭；
- 候选人流程 8 阶段状态机，服务端强制合法流转、不可跳步；
- 两轮面试实体化：每轮有准确面试时间、面试评价（必填）与通过/不通过结论，结论驱动流程推进（HR 面由 HR 评价、负责人面由部门负责人评价）；
- Offer 审批链：HR 发起（建议薪资）→ 部门负责人审批并**确定最终薪资**（必填），驳回回退并留原因；
- 全链路时间线：每次流转记录操作人、时间、原因，可回溯。

**2. 角色化工作台**
- 候选人中心：全局按候选人跟进，支持阶段/部门/岗位/关键词筛选；
- 我的待办：按角色自动汇总（HR：待初筛/待安排面试/待评价/待发起 Offer；负责人：岗位审批/负责人面评价/Offer 审批），带数量徽标，可直接操作。

**3. AI 简历智能匹配（应对大量简历场景）**
- 简历解析（LLM 结构化抽取）+ 硬性条件检查（学历/年限/必备技能）+ 语义相似度（pgvector）+ LLM 评委打分，输出 0-100 综合分与可解释的匹配理由（优势/不足/风险/评语）；
- 漏斗式成本控制（仅前列候选人走 LLM 精排）；无 API Key 时自动降级规则匹配；
- 中文 PDF 简历经 pdftotext 提取，实测解析评分准确。

## 四、技术实现

- **架构**：前后端分离；Go 后端（Gin + pgx + asynq 任务队列 + Eino 编排 DeepSeek）+ React 前端（内部端 Ant Design、外部端 Tailwind），单一共享类型契约；
- **基础设施**：PostgreSQL 17 + pgvector、Redis、MinIO，Docker 容器化部署于阿里云香港 ECS，Nginx + HTTPS（DigiCert 证书）；
- **代码仓库**：https://github.com/Fanxiwen/recruitmate （GitHub Actions CI 全绿：Go vet/build/test + 前端 lint/typecheck/build）；
- **质量保障**：状态机/匹配引擎单元测试、OA 全链路 API 测试 15 项、Playwright 关键路径 E2E、冒烟测试 15 项，全部通过。

## 五、推荐演示路径（约 5 分钟）

1. 求职者视角：打开 https://zpjmhrsys.tech 投递一份简历（支持上传 PDF 或粘贴文本），约 10 秒后生成 AI 匹配分；
2. HR 登录 https://zpjmhrsys.tech/hr：「我的待办」处理新简历（初筛）→ 安排 HR 面（选时间）→ 完成后填写评价并确认通过 → 安排负责人面；
3. 切换部门负责人账号：完成负责人面评价 → 审批 Offer 并确定最终薪资；
4. 回到候选人中心查看该候选人完整时间线与两轮面试记录。
